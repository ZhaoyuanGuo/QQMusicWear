QQMusicWear

多源合一 · 腕上畅听

专为 Wear OS 打造的第三方音乐客户端，内置六种音乐源，一次加载一个——主题色、品牌名、桌面图标随源切换。圆表方表自适应、表冠导航、卡拉OK歌词，一只手、一块表即可完成从发现到播放的全部操作。

QQ音乐 酷狗音乐 酷狗概念版 网易云音乐 番茄音乐 番茄畅听
下载 APK 查看源码

核心功能

多音乐源

内置六种音乐源，设置内一键切换，一次只加载一个；主题色、品牌名、桌面图标随源切换，登录凭据按源加密隔离，QQ音乐源支持 QQ / 微信两种扫码

内容发现

推荐卡片首页 / 每日推荐 / 私人漫游，排行榜、歌单广场、歌手页、专辑页、搜索分区，以及播客电台与动态关注

播放与下载

标准 / 高品质 / 无损 / Hi-Res 音质选择，播放失败自愈降级重试，队列与进度持久化，批量下载与断网自动兜底

本地音乐与听歌识曲

扫描系统媒体库与自有目录成列表播放，无网也能听；录几秒环境音即可识别当前歌曲（无麦克风设备自动隐藏入口）

卡拉OK歌词

逐行接力填充效果，原文 / 翻译 / 罗马音三轨显示，已下载歌曲自动缓存歌词，离线同样可用

手表深度适配

圆表 / 方表双布局自动识别，表冠导航队列与列表，6 种播放进度样式，低配置设备流畅优先模式

插件与安全

协议逻辑外置为 JS 音乐源插件，在本地沙箱中运行，Ed25519 签名强制校验，多镜像容灾下载

下载应用

Wear OS / Android

v3.1.0
  • Wear OS 4+ 手表，或 Android 8.1（API 27）及以上
  • 六种音乐源，QQ / 微信双扫码登录，凭据按源加密隔离
  • 本地音乐、听歌识曲与应用内检查更新
  • 圆表 / 方表自适应 + 表冠导航
  • 卡拉OK歌词与多音质播放
  • 播放队列持久化与批量下载
  • 音乐源插件签名校验与多镜像容灾
下载 APK 安装包

通过 adb 或文件传输安装到手表，也可在 GitHub Releases 查看历史版本

安装说明

Wear OS / Android
  • 支持 Wear OS 4+，非 Wear OS 手表 Android 8.1 起可运行
  • 各音乐源均支持扫码登录
  • 首次启动引导阅读用户协议
  • 自动从公开镜像下载音乐源插件
  • 镜像不可用时可从存储导入插件文件
  • 安装包内不含任何协议实现
查看安装文档

adb install QQMusicWear-v<版本号>.apk
